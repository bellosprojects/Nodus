# 🎨 Software de Diagramación Colaborativo
Un editor de diagramas colaborativo de alto rendimiento construido con **FastAPI** y **Skia**.

## 🛠️ Stack Tecnológico
- **Frontend:** Tauri + SolidJS + CanvasKit
- **Backend:** [Python 3.10+](https://www.python.org/) con [FastAPI](https://fastapi.tiangolo.com/).
- **Despliegue:** [Render](https://render.com/) (Web Service).
